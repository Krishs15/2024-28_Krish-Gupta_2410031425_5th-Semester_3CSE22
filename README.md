## 📌 About the Internship

The internship focused on building a strong practical foundation in full-stack development, covering Python fundamentals, backend APIs with FastAPI, database integration with SQLAlchemy, and frontend development using React. The program followed a structured, week-wise curriculum combining conceptual learning with practical exposure, culminating in a capstone project titled "Markdown to HTML Converter". EduSkills Academy (ISO 9001:2015 certified) runs this program under the patronage of the AICTE National Internship Portal.

## 🎯 Objectives

The primary objective was to design a robust software utility that automates the translation of plain text formatted with Markdown syntax into equivalent HTML code. This required developing a sequential processing pipeline to handle key elements such as header levels, text emphasis, inline code segments, and hyperlinks efficiently. Performance optimization and code quality were ensured by utilizing modern tools and algorithms.
